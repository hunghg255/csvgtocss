# csvgtocss docs

React + Vite site with two pages:

- **Docs** (`#/`) — usage, configuration, and how the CSS icons work.
- **Icons** (`#/icons`) — a browser for the icons generated from `../test/svg`.

The icon CSS is generated by csvgtocss itself when the site starts or builds
(`scripts/gen-icons.mjs` → `src/generated/`). If the library in the repository
root is not built yet, the script runs `pnpm install` and `pnpm build` there
first, so the docs can be built on their own:

```bash
cd docs
pnpm install
pnpm dev      # or: pnpm build && pnpm preview
```

If you change the library, run `pnpm build` in the root again to refresh the icons.

## Deploying (Vercel, Netlify, …)

- Root directory: `docs`
- Build command: `pnpm run build`
- Output directory: `dist`

The build needs the rest of the repository (the library source and `test/svg`).
On Vercel, keep "Include files outside the root directory in the Build Step" enabled (the default).

`pnpm build` outputs a static site to `docs/dist/` with relative asset paths,
so it can be hosted from any sub-path (e.g. GitHub Pages).
