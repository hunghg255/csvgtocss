# csvgtocss docs

React + Vite site with two pages:

- **Docs** (`#/`) — usage, configuration, and how the CSS icons work.
- **Icons** (`#/icons`) — a browser for the icons generated from `../test/svg`.

The icon CSS is generated by csvgtocss itself when the site starts or builds
(`scripts/gen-icons.mjs` → `src/generated/`), so build the library first:

```bash
# repository root
pnpm install && pnpm build

# docs
cd docs
pnpm install
pnpm dev      # or: pnpm build && pnpm preview
```

`pnpm build` outputs a static site to `docs/dist/` with relative asset paths,
so it can be hosted from any sub-path (e.g. GitHub Pages).
